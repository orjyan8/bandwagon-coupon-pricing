**適合月付或半年付的情況：**

優惠券不一定會改變計費週期的經濟性。比如 20G 年付方案原價 US$49.99，40G 半年付方案原價 US$52.99。40G 的一次付款金額只高約 US$3，但如果連續使用兩年，年付總成本就需要重新計算。
